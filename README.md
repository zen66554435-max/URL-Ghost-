# زاحف المواقع — Site Crawler v2

أداة زحف دقيقة بواجهة عربية كاملة (RTL) لاكتشاف صفحات أي موقع داخل نفس النطاق، مع قياسات مصداقية لكل صفحة وتصدير النتائج.

## ما الذي تقيسه الأداة لكل صفحة؟

- **حالة HTTP** الفعلية بعد اتباع التحويلات + الرابط النهائي بعد التحويل.
- **زمن الاستجابة** بالمللي ثانية و**حجم الصفحة**.
- **العنوان** (title) و**الوصف** (meta description) و**أول H1** ولغة الصفحة.
- **canonical** وما إذا كان يطابق رابط الصفحة نفسه (كشف المحتوى المكرر).
- **noindex / nofollow** من وسم meta robots.
- عدد **الروابط الداخلية والخارجية** في الصفحة.
- مصدر الاكتشاف (رابط داخلي أو sitemap).

## الدقة والمصداقية

- قراءة صحيحة للترميز (charset) من ترويسة HTTP أو وسم `<meta charset>` — تُحل مشكلة العناوين العربية المشوّهة.
- محلل **robots.txt** متوافق مع أسلوب Google: دعم `*` و`$` وقواعد Allow/Disallow واختيار أطول قاعدة مطابقة.
- دعم **sitemap** العادي و**المضغوط `.gz`** وفهارس sitemaps المتداخلة (حتى 40 ملفاً).
- إزالة وسوم التتبع (`utm_*`، `fbclid`، `gclid`…) حتى لا تُحسب الصفحة الواحدة مرتين.
- تصنيف أخطاء الشبكة برسائل عربية واضحة (DNS، رفض الاتصال، شهادة الأمان، مهلة…).
- تنظيف تلقائي للعمليات المنتهية من الذاكرة بعد 30 دقيقة.

## تشغيل محلياً

```bash
npm install
npm start
```

ثم افتح: http://localhost:3000

## النشر على Render

1. ارفع المشروع إلى GitHub.
2. في Render اختر **New → Web Service** واربط المستودع.
3. Build Command: `npm install` — Start Command: `npm start`
4. اترك Node 20+. (يوجد `render.yaml` جاهز.)

## التشغيل عبر Docker

```bash
docker build -t site-crawler .
docker run -p 3000:3000 site-crawler
```

## واجهات API

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/crawl` | بدء عملية زحف جديدة |
| GET | `/api/crawl/:id` | حالة العملية والنتائج |
| POST | `/api/crawl/:id/cancel` | إيقاف العملية |
| GET | `/api/crawl/:id/csv` | تصدير النتائج CSV |
| GET | `/api/crawl/:id/json` | تصدير النتائج JSON |

## ملاحظات

- الزحف يبقى داخل نفس الـhostname فقط.
- لا يزحف إلى ملفات الصور/CSS/JS كصفحات.
- حد افتراضي 1000 صفحة لكل عملية (حتى 10,000).
- استخدم الأداة على مواقع تملكها أو لديك إذن بفحصها.
